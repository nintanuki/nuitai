The tabletop game

Nuitai is going to have a tabletop roleplaying game with its own rules, not a version of Dungeons & Dragons. The manual is not written yet. This page is where it will live.

What exists so far

  • The element job system: six elements, every character has two, and each pair is a job.
  • The fifteen jobs: what each pair is like to play.
  • Magic is motion: a spell needs movement or breath, so a character who is tied up cannot cast.

The same jobs and elements run the battle test, so the video game and the tabletop game grow from one set of ideas.
